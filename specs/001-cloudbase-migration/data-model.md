## Collection: `recipes`

### Schema

```javascript
{
  _id: String,                    // Auto-generated by CloudBase
  name: String,                   // REQUIRED: Recipe name (e.g., "宫保鸡丁")
  cuisine: String,                // REQUIRED: Cuisine type (e.g., "川菜", "粤菜")
  imageUrl: String,               // OPTIONAL: Recipe image URL
  ingredients: Array<String>,     // REQUIRED: List of ingredients with quantities
  steps: Array<String>,           // REQUIRED: Cooking steps
  cookTime: Number,               // REQUIRED: Cooking time in minutes
  difficulty: Number,             // REQUIRED: Difficulty 1-5
  tags: Array<String>,            // OPTIONAL: Tags (e.g., ["辣", "家常"])
  favoriteCount: Number,          // DEFAULT: 0 - Internal popularity
  viewCount: Number,              // DEFAULT: 0 - For heat score calculation
  heatScore: Number,              // COMPUTED: favoriteCount + viewCount * 0.1
  isDailyRecommended: Boolean,    // DEFAULT: false - Flag for Market section
  sourceType: String,             // ENUM: 'migrated' | 'ai_curated' | 'manual'
  aiSource: {                     // OPTIONAL: Only for ai_curated
    modelUsed: String,            // 'hunyuan' | 'deepseek'
    searchedAt: Date,             // When AI search occurred
    externalPopularity: Number    // External popularity metric if available
  },
  createdAt: Date,                // Auto-generated
  updatedAt: Date                 // Auto-updated on changes
}
```

### Validation Rules (CloudBase Security Rules)

```json
{
  "read": true,
  "write": "auth != null && (resource.data._openid == auth.openid || resource.data.sourceType == 'manual')",
  "validate": {
    "name": {
      "type": "string",
      "minLength": 1,
      "maxLength": 100
    },
    "cuisine": {
      "type": "string",
      "enum": ["川菜", "粤菜", "湘菜", "鲁菜", "苏菜", "浙菜", "闽菜", "徽菜", "其他"]
    },
    "cookTime": {
      "type": "number",
      "minimum": 1,
      "maximum": 1440
    },
    "difficulty": {
      "type": "number",
      "minimum": 1,
      "maximum": 5
    }
  }
}
```

### Indexes

```javascript
// Essential indexes for query performance
db.collection('recipes').createIndex({ cuisine: 1 })
db.collection('recipes').createIndex({ isDailyRecommended: 1, createdAt: -1 })
db.collection('recipes').createIndex({ heatScore: -1 })
db.collection('recipes').createIndex({ name: 'text' })  // For search
```


## Collection: `ai_generation_logs`

### Schema

```javascript
{
  _id: String,
  jobId: String,                  // Unique job identifier (UUID)
  status: String,                 // ENUM: 'running' | 'completed' | 'failed' | 'fallback'
  scheduledAt: Date,              // When trigger fired
  startedAt: Date,                // When job started
  completedAt: Date,              // When job finished
  recipesSearched: Number,        // How many recipes AI found
  recipesAdded: Number,           // New non-duplicate recipes added
  recipesDuplicated: Number,      // Duplicates detected and skipped/replaced
  recipesFallback: Number,        // Existing recipes used as fallback
  modelUsed: String,              // 'hunyuan' | 'deepseek'
  fallbackToExisting: Boolean,    // Whether fallback was used
  errors: Array<{                 // Error log if any
    code: String,
    message: String,
    timestamp: Date
  }>,
  searchQuery: String,            // The query sent to AI
  executionTimeMs: Number         // Total execution time
}
```

### Validation Rules

```json
{
  "read": false,                  // Internal only, no direct access
  "write": "auth != null && resource.data.jobId != null"
}
```

## Query Patterns

### Frontend Queries (SDK Direct Access)

```javascript
// 1. Get all recipes by cuisine
db.collection('recipes').where({ cuisine: '川菜' }).get()

// 2. Get today's market recipes
db.collection('market_daily')
  .where({ date: '2026-03-06' })
  .get()
  .then(res => {
    // Fetch full recipe details
    const recipeIds = res.data[0].recipes.map(r => r.recipeId)
    return db.collection('recipes').where({
      _id: db.command.in(recipeIds)
    }).get()
  })

// 3. Search recipes by name
db.collection('recipes')
  .where({
    name: db.RegExp({ regexp: '.*宫保.*', options: 'i' })
  })
  .get()

// 4. Get user favorites
db.collection('users')
  .where({ _openid: '{openid}' })
  .get()
  .then(res => {
    const favorites = res.data[0].favorites
    return db.collection('recipes').where({
      _id: db.command.in(favorites)
    }).get()
  })

// 5. Get recommendations
db.collection('recipes')
  .where({
    cuisine: db.command.in(preferredCuisines),
    heatScore: db.command.gt(10)
  })
  .orderBy('heatScore', 'desc')
  .limit(10)
  .get()
```

### Cloud Function Queries

```javascript
// 1. Find potential duplicates (name similarity)
// Executed in cloud function with cached recipe list
const existingRecipes = await db.collection('recipes').get()
// Apply Levenshtein similarity in JS

// 2. Get top recipes by heat score
await db.collection('recipes')
  .orderBy('heatScore', 'desc')
  .limit(100)
  .get()

// 3. Get seasonal recipes (based on ingredients)
const seasonalIngredients = getSeasonalIngredients(new Date())
await db.collection('recipes')

    ingredients: db.command.elemMatch({
      $regex: new RegExp(seasonalIngredients.join('|'))
    })
  })
  .get()
```

## Security Considerations

1. **Recipe Data**: Public read, restricted write (only cloud functions or manual admin)
2. **User Data**: Private - users can only read/write their own documents
3. **Logs**: No direct access - cloud function internal only
4. **Market Daily**: Public read, no direct write (cloud function only)

---

## Performance Optimization

1. **Index Strategy**: All query fields indexed (cuisine, heatScore, isDailyRecommended)
2. **Pagination**: Use `.limit()` and `.skip()` for large lists
3. **Batch Operations**: Process data migration in batches of 100
4. **Caching**: Cache market_daily reads for 1 hour on frontend
